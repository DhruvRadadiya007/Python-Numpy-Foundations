# 🧮 Python NumPy Foundations

A beginner-friendly collection of **NumPy examples and practice code** covering the fundamental concepts needed to work with numerical data in Python.

This repository is designed as a learning resource for students, beginners, and anyone starting their journey in **Python, Data Science, and Machine Learning**.

## 📚 What You'll Learn

The examples are organized step-by-step, starting with creating NumPy arrays and gradually moving toward more useful array operations.

### 1. Creating Arrays

Learn different ways to create NumPy arrays, including:

* 1D and 2D arrays
* Arrays from lists and tuples
* `zeros()`
* `ones()`
* `full()`
* `eye()`
* `arange()`
* `linspace()`
* Random arrays
* Understanding data types

### 2. Array Attributes

Understand important NumPy array properties such as:

* `shape`
* `ndim`
* `size`
* `dtype`
* `itemsize`

### 3. Indexing & Slicing

Practice accessing and extracting data from arrays using:

* Basic indexing
* Negative indexing
* 1D slicing
* 2D indexing and slicing
* Boolean indexing
* Conditional filtering
* Fancy indexing
* Array views and shared memory
* Creating independent copies with `copy()`

### 4. Array Operations

Learn how NumPy performs fast operations on arrays:

* Addition
* Subtraction
* Multiplication
* Division
* Power operations
* Universal functions such as `sqrt()`, `exp()`, `log()`, `sin()`, and `cos()`
* `add.reduce()`
* `add.accumulate()`
* Broadcasting
* Aggregation functions
* Statistical functions such as:

  * `sum()`
  * `mean()`
  * `median()`
  * `std()`
  * `var()`
  * `min()`
  * `max()`
  * `argmin()`
  * `argmax()`

### 5. Random Module

Explore NumPy's random functionality:

* Random integers with `randint()`
* Normally distributed values with `randn()`
* Uniform random values with `rand()`
* Using `random.seed()` for reproducible results

### 6. Reshaping & Stacking

Learn how to change and combine arrays:

* `reshape()`
* `flatten()`
* Horizontal stacking with `hstack()`
* Vertical stacking with `vstack()`

## 🎯 Purpose of This Repository

This repository is primarily created for **learning and practice**.

The examples are intentionally simple so that you can understand what each NumPy function does by running the code and observing the output.

It can be useful for:

* 🐍 Learning Python NumPy
* 📊 Preparing for Data Science
* 🤖 Building a foundation for Machine Learning
* 🎓 Academic practice
* 💻 Practicing array manipulation
* 📖 Quick revision of NumPy concepts

## 🚀 How to Use

Clone the repository:

```bash
git clone https://github.com/DhruvRadadiya007/Python-Numpy-Foundations.git
```

Install NumPy:

```bash
pip install -r requierments.txt
```

Then run any example:

```bash
python 1_Creating_Arrays.py
```

Follow the files in numerical order to learn the concepts progressively.

## 🗂️ Files

| File                          | Topic                                       |
| ----------------------------- | ------------------------------------------- |
| `1_Creating_Arrays.py`        | Creating NumPy arrays                       |

## 🌱 Learning Approach

The goal is not just to memorize NumPy functions, but to understand **how arrays work and how NumPy can be used to manipulate numerical data efficiently**.

> **Learn the concept → Run the code → Experiment → Modify it → Understand the result**
